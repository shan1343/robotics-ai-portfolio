# Academic exam
For multi-file exam setup or full-course coverage, read [source coverage](../../references/source-coverage.md). Reconcile the complete requested source inventory; a prioritized topic map does not certify full source reading. A setup-only request ends with a verified starting point and explicit remaining coverage, without requiring an immediate quiz.

Read [the operating contract](../../references/operating-contract.md). For continuation, learning writeback or material portfolio evidence, read [learning and continuity](../../references/learning-and-continuity.md).

1. Recover the course, exact assessment, last checkpoint and existing OPEN/WEAK learning evidence. Verify scope, date, permitted aids and format in official course notices/materials; do not infer scope from what sources happen to be uploaded. Surface an unresolved scope conflict before calling a plan complete.
2. Build a compact coverage map from verified scope and available course sources: topic, source pointer, available observed learning evidence, unassessed gap and next practice. Keep it in the existing working surface when authorized; do not create another tracking database. Prioritize weaknesses while retaining coverage of unassessed topics.
3. Ask a recall or problem-solving question for one priority topic, with answer withheld. Wait for the user's actual attempt. Simulated student answers, passive reading and summary generation do not count as assessment.
4. Give immediate feedback and classify errors as concept, retrieval, problem setup, calculation, units, syntax or time strategy as appropriate. Explain the smallest repair; distinguish hints from independent success.
5. Use a changed-context transfer question and a later retest when appropriate; wait for each user attempt. Do not certify readiness from one rehearsed answer or unseen topics. Save only observed evidence to the existing Learning Profile with readback when authorized.

## Completion

Report tested coverage, untested coverage, actual error trends and the next practice. Readiness stays limited to observed evidence; a generated study guide alone does not complete exam preparation.
