# IDC RoboCon 2023 · 온라인 환경에서 로봇을 조작하다

[← 포트폴리오](../README.md) · [활동 시간선](../experience.md)

**2023 · Team 10 Gray · 온라인 참가와 Ubuntu/ROS 환경 실행·로봇 조작 경험**

2022년 RoboCon에서 기구를 만들었던 경험에 이어, 2023년에는 온라인 로봇 대회 환경을 준비하고 로봇을 조작하는 활동에 참여했습니다. 제 역할은 제공된 환경을 실행하고 온라인 조작에 참여하는 것이었습니다. 시뮬레이터·웹서버·제어 패키지 전체를 직접 개발했거나, 팀의 현장 기체를 혼자 설계했다는 뜻은 아닙니다.

## 당시 자료로 복원한 실행 흐름

이번 설명은 Drive의 `install.sh`, `freeplayexample.sh`, `IDC2023_online_presentation.pdf`, 팀 발표 `10_Gray_Robocon_9thAUG Presentation`을 직접 읽어 작성했습니다. 설치 스크립트를 지금 실행하거나 시스템에 패키지를 새로 설치한 것은 아닙니다.

| 단계 | 원본에서 확인한 구성 | 참여 경험을 설명하는 관점 |
|---|---|---|
| 운영체제·ROS | 안내 문서의 Ubuntu 22.04 LTS, ROS 2 Humble | 제공된 로봇 실행 환경을 준비 |
| 시뮬레이션·제어 | 설치 스크립트의 Gazebo, controller manager, joint-state broadcaster, trajectory/velocity controller | 화면의 로봇과 관절 명령이 연결되는 환경 사용 |
| 입력·통신 | 키보드 제어 패키지, Node.js 웹서버, rclnodejs·Socket.IO | 조작 입력과 경기 연결의 실행 조건 확인 |
| 팀 구분·실행 | properties.yaml의 TeamNo, 명령별 ROS_DOMAIN_ID | 같은 환경에서 팀별 통신 영역 설정 |
| 자유실행 | robot_gazebolaunch.py와 /free_play_command 서비스 | 대회 전 로봇 실행·조작 예제 |

자유실행 스크립트에는 다음과 같은 실제 명령이 남아 있습니다. **대회 제공 예제의 짧은 발췌**이며 개인 작성 코드로 표시하지 않습니다.

제공 스크립트는 팀 번호에서 ROS_DOMAIN_ID를 설정한 뒤 Gazebo 기반 자유실행 서비스로 연결하는 순서입니다. 원문 스크립트는 외부 재게시 허가를 확인할 때까지 복사하지 않습니다.

설치 스크립트에 명시된 시뮬레이션 기반 저장소는 [F-H-P/IDC-Simulation](https://github.com/F-H-P/IDC-Simulation)입니다. 이 링크의 공개 접근 가능 여부는 확인했지만, upstream 전체 코드의 재배포 허가나 제 개인 기여를 의미하지 않습니다. 코드 전체를 복제하지 않고 출처로 연결합니다.

## 온라인 참가와 현장 팀 결과의 구분

온라인 안내에는 심판이 보낸 URL을 설정하고 `run.sh`를 실행하는 흐름, 온라인 점수와 현장 바구니의 재료가 연결되는 경기 규칙이 있습니다. 팀 발표에는 물체를 집는 장치, 회전하는 판을 기울여 바구니로 보내는 운반 전략, DC·서보 모터와 아크릴 베이스, Fusion 360을 이용한 구상이 담겨 있습니다.

이 자료는 **온라인 경기와 현장 팀 작업이 연결된 배경**을 설명합니다. 제 개인 경험은 Ubuntu/ROS 환경 실행·온라인 로봇 조작이며, 발표에 나온 모든 CAD와 현장 제작을 개인 성과로 가져오지 않습니다. 실제 경기장·팀 로봇 사진은 교수·CTO용 Notion에 첨부돼 있습니다.

## 확인하지 못한 부분도 남깁니다

사용자 기억에는 MuJoCo를 사용했다는 진술이 있지만, 이번에 읽은 설치·자유실행 스크립트는 Gazebo를 명시합니다. 두 자료가 완전히 같은 시점과 환경을 가리키는지는 확인되지 않았습니다. 따라서 제목과 개인 역할에는 **온라인 로봇 조작**을 쓰고, 위 기술 표는 **제공 자료에 적힌 환경**으로 구분합니다.

온라인 안내 PDF에는 파일명·보존 시점과 맞지 않는 `Q1 OF 2025` 문구도 있습니다. 이를 활동 연도의 근거로 쓰지 않았습니다. 2023년 Team 10 참여는 사용자 진술과 팀 발표의 표기를 기준으로 남깁니다. 개인 코드 수정량·경기 점수·수료 여부를 원본 근거 없이 추가하지 않았습니다.

## 남은 경험

이 활동은 제공된 로봇 환경을 읽고 실행하면서 운영체제, ROS 통신, 제어 입력, 경기 시스템이 어떻게 연결되는지 접한 경험입니다. 이후 Humanoid Challenge에서 환경·토픽·Planning Scene 통합을 다루기 전의 학습 과정으로 소개합니다.

원본 Drive 식별자·검수한 파일은 개인 비공개 작업 기록에 보존했습니다. 학생·팀원 개인정보나 권한 없는 팀 자료 전체를 외부 저장소로 복제하지 않습니다.
