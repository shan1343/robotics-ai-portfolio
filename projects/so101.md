# SO-101 · 로봇 학습 교육을 준비하는 SHAPE TA

[← 포트폴리오](../README.md) · [현재 팀 교육 흐름과 작업 이력](../experience.md)

**2026.09–현재 | SHAPE 교육 TA · LeRobot / Hugging Face · RL·IL 교육 준비**

제가 SO-101에서 지향하는 역할은 **모터 조립 자체를 주도한 사람**보다, 초심자가 로봇을 실제로 조작하고 데이터를 모아 **정책을 학습·평가하는 과정으로 넘어갈 수 있도록 돕는 교육조교**에 가깝습니다.

현시점에 증거로 제시할 수 있는 작업은 장비 준비·연결 문제 추적·조립 보조자료 작성까지입니다. 팀 교육과정은 그다음에 **강화학습(RL), 데이터 수집, 모방학습(IL), Hugging Face/LeRobot와 공개 VLA**로 이어질 계획입니다. 이 계획을 이미 제가 강의·모델 학습·로봇 배포까지 완료한 것으로 포장하지 않습니다.

## 팀 교육 과정과 제가 준비할 역할

| 교육 단계 | 교육 내용 · 기술의 목적 | 조교로서 준비·지원할 것 | 확인해야 성과로 쓸 수 있는 것 |
|---|---|---|---|
| **W2–4 · 장비·제어** | Leader–Follower calibration과 teleoperation, 카메라·관절 상태·제어 입력의 관계 이해 | 장비별 관절 ID·방향·범위, 연결·복구 체크리스트, 실습 순서 정리 | 실제 두 로봇의 teleop 반복 동작 영상·로그 |
| **W5–6 · 강화학습(RL)** | 상태/관측, 행동, 보상, 종료 조건, PPO 개념과 sim-to-real·domain randomization 기초 | 실습 예제의 reward/observation/action 해설, seed/checkpoint·학습 곡선·실패 조건을 함께 읽도록 지원 | 특정 run의 config·체크포인트·평가 영상, 동일 조건 비교 |
| **W7 · 시연 데이터** | Leader–Follower로 시연 episode를 수집해 정책 학습의 입력을 마련 | 카메라 프레임·관절 상태·action의 timestamp, episode 종료·실패 레이블, 누락값·시간 정합성 점검 | 실제 데이터셋 구조·품질 검수표·샘플 episode |
| **W8 · 모방학습(IL)** | 시연 데이터 기반 ACT / Diffusion Policy 이해, 학습·rollout 비교 | data/action normalization, camera view, training configuration과 rollout failure 유형을 구분해 설명 | 학습 실행 로그, 시연 영상·정책 rollout, 실패 및 재수집 기록 |
| **W9 · Hugging Face·LeRobot·VLA** | 로봇 데이터셋·policy와 공개 모델 공유/사용, 공개 VLA와 기존 IL의 차이 비교 | Hugging Face 데이터셋·model card 읽기, LeRobot 형식·라이선스·기체 호환 조건 설명, 재현 절차 보조 | 출처·버전·라이선스·inference 조건을 남긴 실제 실행 결과 |

**일정은 당시 SHAPE 교육안의 주차별 목표**입니다. 실행 날짜·수업 진행·정량 성능은 원본 기록과 추후 실습 여부를 확인해야 합니다. 위 표의 대부분은 *계획·준비 범위*입니다.

## Hugging Face/LeRobot를 왜 활용하려 하나

실물 로봇에서 수집한 **관측(카메라·관절 정보)과 행동(관절 명령)**을 연결해 시연을 기록하고, 다른 사람이 같은 형식으로 읽고 학습·평가할 수 있게 하는 것이 중요합니다.

특히 다음 차이를 교육에서 명확히 설명하고자 합니다.

- **RL:** 환경에 정의한 관측·행동·보상·종료 조건을 통해 정책을 학습합니다. 시뮬레이션에서 학습했다고 곧바로 SO-101 실물에 안전하게 배포되는 것은 아닙니다.
- **IL:** Leader–Follower 등의 **사람 시연 데이터**를 바탕으로 행동을 모방하도록 학습합니다. ACT와 Diffusion Policy는 후보 접근법이며 현 단계에서 교육 준비 대상으로 기록합니다.
- **Hugging Face/LeRobot:** 로봇 데이터셋·정책·훈련 및 평가 도구의 공유와 재현 경로로 다룹니다. **LeRobot를 쓴다는 말이 곧 RL과 IL을 모두 실물 SO-101에서 실행했다는 뜻은 아닙니다.**
- **공개 VLA:** vision+language+action 구조를 이해하고 기존 IL 정책과 비교할 후속 주제입니다. 실제 기체·카메라·action space 호환 및 라이선스 확인 없이 모델을 바로 투입하지 않습니다.

핵심은 최신 모델 이름을 많이 아는 것이 아니라 **데이터가 어디서 생성돼 어떤 정책의 어떤 action으로 실행되는지**를 설명하고, 실습이 실패했을 때 데이터를 확인할 수 있는 능력을 키우는 것입니다.

## 조교 역할을 통해 만들고 싶은 교육 산출물

1. **재현 가능한 실습 시작점:** 모터와 포트 확인, calibration, teleoperation, 안전 중단과 복구까지의 체크리스트.
2. **데이터 검수표:** episode 길이·카메라·관절 상태·action 순서와 타임스탬프 정합성, 실패 사례 구분.
3. **학습 실험 기록:** 사용한 dataset 버전·policy 설정·seed·checkpoint·학습 곡선과 오류 원인.
4. **정책 검증 비교:** 시연 데이터의 quality와 학습 결과, 시뮬레이션과 실제 로봇의 실행 성공/실패를 별도로 기록.
5. **초심자 가이드:** 처음 하는 팀원도 스스로 재실행해 보고, 실패한 단계를 질문할 수 있게 만드는 짧은 실습 설명.

이들은 **후속 교육에서 만들 계획의 산출물**입니다. 추후 실습이 진행되면 해당 과정의 실제 사진·로그·교안·테스트를 근거와 함께 추가하겠습니다.

## 지금까지 실제로 수행·확인한 기반

- SO-101 **2세트의 24개 모터 ID 및 관절 대응 설정·검수**, 장비 구분·정비·재포장 기록.
- Windows에서 USB 장치가 보여도 WSL/Linux/LeRobot에서 serial port가 안 보이는 원인을 전원·USB→Windows→WSL 전달→Linux `ttyACM0`→LeRobot 단계로 나눠 추적.
- Leader/Follower·관절 위치·horn 방향·배선·조립 순서와 ID 중복 주의사항을 설명하는 **4쪽 조립 보조자료 제작**.
- 도구와 로봇을 연결하는 초기 문제를 교육 참가자가 반복해서 겪지 않도록 절차를 문서화하고 다음 교육 단계의 기반을 준비.

이 장비 작업은 중요한 **기반 구축**이지만 포트폴리오의 주제가 아닙니다. **메인 주제는 이 기반 위에서 RL·IL·Hugging Face/LeRobot을 배우고 설명할 수 있는 교육 프로그램을 팀과 만들어 가는 조교 경험과 미래 계획**입니다.

### 실물 조립·교육 자료의 공유 범위

직접 작성한 4쪽 교육 보조자료와 SO-101 작업 사진은 교수·CTO 제한 Notion에 보존합니다. SHAPE와 후원기관 명칭이 들어 있는 팀 교육자료의 외부 재게시 권한을 확인하기 전에는 GitHub에 원본 이미지를 올리지 않습니다. 위 RL·IL·LeRobot 교육 과정은 미래 실습 계획이며 완료 성과가 아닙니다.

**기여·검증 경계:** 실제 완료가 확인된 것은 장비 설정·연결 오류 추적·교육자료 제작입니다. RL 학습, ACT/Diffusion 정책 훈련, 데이터셋 업로드, VLA 모델 배포, 수업 효과 측정은 아직 완료한 성과로 주장하지 않습니다. 팀의 연구·교육 계획과 본인의 수행 범위를 구분합니다.
