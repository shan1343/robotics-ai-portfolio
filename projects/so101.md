# SO-101 · 학생들이 실습할 장비와 환경 준비

[첫 화면](../README.md) · [교육·SHAPE 활동](../experience.md)

**2026년 9월–현재 · SHAPE 교육 TA, 장비 조립·점검, WSL 환경과 보조자료 준비**

SHAPE 로봇 교육을 준비하며 SO-101 두 세트를 조립·점검했습니다. 모터 24개의 ID와 관절 대응을 맞추고 장비를 구분해 정비·재포장했습니다. 학생들이 따라 할 WSL 실습 환경을 준비하는 과정에서는 USB 장치가 Windows에 보이는데 Linux와 LeRobot에서는 연결되지 않는 등 여러 오류를 만났습니다.

## 장비에서 프로그램까지 연결을 추적하기

```mermaid
flowchart LR
  A[전원·USB 연결] --> B[Windows 장치 인식]
  B --> C[WSL로 USB 전달]
  C --> D[Linux serial 장치]
  D --> E[LeRobot 연결]
```

Windows의 장치 인식만 보고 연결이 끝났다고 판단하지 않고, WSL 전달과 Linux의 `ttyACM0`, LeRobot의 포트 선택을 단계별로 확인했습니다. 장치·포트·프로그램 중 어디에서 끊겼는지 구분하고, 학생들이 같은 오류를 만났을 때 확인할 순서를 정리했습니다. 이 경험은 특정 Windows 환경의 연결 준비이며 모든 PC에서 같은 결과를 보장하는 설치 도구는 아닙니다.

| 실제 작업 | 확인한 내용 |
|---|---|
| 모터 24개 설정·점검 | Leader/Follower와 관절의 ID 대응, 장비 구분, ID 중복 주의사항 |
| 조립·배선 | 관절 위치, horn 방향, 배선과 조립 순서 |
| WSL 환경 준비 | 전원·USB → Windows → WSL → Linux serial → LeRobot 연결 경로 |
| 보조자료 제작·사용 | 위 내용을 4쪽 자료로 정리해 실제 실습 준비에 사용 |

## 실제로 사용한 4쪽 조립 보조자료

모터 ID 표만으로는 조립할 위치와 방향을 한 번에 이해하기 어려웠습니다. Leader/Follower의 관절 위치, horn 방향, 배선·조립 순서와 주의사항을 함께 볼 수 있게 자료를 구성했습니다. 장비를 준비하며 참고하는 보조자료로 사용했고, 작업 사진과 원본은 Notion 포트폴리오에 두었습니다.

## 이어서 준비하는 교육

현재 장비와 연결 환경을 바탕으로 팀 교육의 다음 실습을 지원하려 합니다.

| 팀 교육안 | 조교로서 준비할 내용 |
|---|---|
| 장비·제어 | calibration, teleoperation, 시작·정지·연결 복구 순서 |
| 강화학습 | 관측·행동·보상과 학습 설정, 학습 곡선과 실패 조건 읽기 |
| 시연 데이터 | 카메라·관절 상태·action의 순서와 timestamp, episode 구분 |
| 모방학습 | ACT·Diffusion Policy의 데이터·학습 설정과 rollout 비교 |
| Hugging Face·LeRobot | 데이터셋·정책의 출처, 형식, 기체 호환과 재현 절차 |

이 표는 향후 교육 준비 내용입니다. 실제 수행은 장비·WSL 연결 준비와 보조자료 제작·사용까지이며, SO-101 정책 훈련·배포나 수업 효과 측정을 완료한 것으로 표시하지 않습니다.
