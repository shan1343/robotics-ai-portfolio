# SO-101 교육 준비

[첫 화면](../README.md) · [교육·SHAPE 활동](../experience.md)

**2026년 9월–현재 · SHAPE 교육 TA, 장비 조립·점검, WSL 환경과 보조자료 준비**

SHAPE의 로봇 교육을 준비하면서 SO-101 두 세트를 조립하고 모터 24개의 ID와 관절 위치를 점검했습니다. 장비를 재포장할 때에도 Leader/Follower와 관절별 부품을 구분해 다음 실습에서 그대로 사용할 수 있도록 정리했습니다. 학생용 WSL 환경에서는 Windows에 표시된 USB 장치가 Linux와 LeRobot에서는 잡히지 않는 문제가 있어 연결 경로를 단계별로 확인했습니다.

## USB·WSL 연결 오류

```mermaid
flowchart LR
  A[전원·USB 연결] --> B[Windows 장치 인식]
  B --> C[WSL로 USB 전달]
  C --> D[Linux serial 장치]
  D --> E[LeRobot 연결]
```

Windows에서 인식된 USB 장치가 WSL로 전달되는지, Linux에 `ttyACM0`가 생기는지, LeRobot이 올바른 포트를 선택하는지 차례로 확인했습니다. 학생들이 같은 오류를 만났을 때 참고할 점검 순서도 정리했습니다.

| 작업 | 내용 |
|---|---|
| 모터 24개 설정·점검 | Leader/Follower와 관절의 ID 대응, 장비 구분, ID 중복 주의사항 |
| 조립·배선 | 관절 위치, horn 방향, 배선과 조립 순서 |
| WSL 환경 준비 | 전원·USB → Windows → WSL → Linux serial → LeRobot 연결 경로 |
| 보조자료 제작·사용 | 위 내용을 4쪽 자료로 정리해 실제 실습 준비에 사용 |

## 4쪽 조립 보조자료

모터 ID만 적힌 표로는 어느 관절에 부품을 끼우고 horn을 어떤 방향으로 맞춰야 하는지 파악하기 어려웠습니다. 그래서 Leader/Follower별 관절 위치와 배선·조립 순서, 주의사항을 함께 담은 4쪽 보조자료를 만들었습니다. 실제 장비 준비에 사용했으며, 조립 사진과 자료 일부는 Notion 포트폴리오에 실었습니다.

## 앞으로의 교육 준비

현재 장비와 연결 환경을 바탕으로 팀 교육의 다음 실습을 지원하려 합니다.

| 팀 교육안 | 조교로서 준비할 내용 |
|---|---|
| 장비·제어 | calibration, teleoperation, 시작·정지·연결 복구 순서 |
| 강화학습 | 관측·행동·보상과 학습 설정, 학습 곡선과 실패 조건 읽기 |
| 시연 데이터 | 카메라·관절 상태·action의 순서와 timestamp, episode 구분 |
| 모방학습 | ACT·Diffusion Policy의 데이터·학습 설정과 rollout 비교 |
| Hugging Face·LeRobot | 데이터셋·정책의 출처, 형식, 기체 호환과 재현 절차 |
